About and privacy

  • Sign-in is a real Google identity, verified server-side by NUUC-Dispatch and exchanged for a signed identity assertion scoped to this portal — this page never sees or stores your raw Google credential beyond the sign-in moment. The assertion itself is saved in your browser's local storage for up to 45 days so you aren't re-prompted on every visit; Sign out deletes it immediately.
  • Each row arrives already carrying the server's own status display answer (bucket, resolved, icon) — this page re-derives nothing, so it cannot disagree with the sheet or the add-on sidebar about what a status means.
  • Read and write paths are wired. The sync control, per-row Edit, and the assignee status-change control all call the live backend and refresh the list in place — no page reload.
  • The window ages out resolved rows only — an open action is never hidden by it, however long since it was touched, at any window setting.
  • If you belong to more than one team, a Team switcher appears above; if you belong to exactly one, no switcher is shown.
