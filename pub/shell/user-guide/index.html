Northlake UU Tool Suite — User Guide

The Northlake UU Tool Suite (NUUTS) is one Google Workspace add-on that adds Northlake UU's working tools to Google Docs and Sheets. It currently includes three features:

  • Action Items — capture action items in meeting notes and track them in a shared spreadsheet.
  • Format — apply the standard GC formatting rules to a document.
  • Export — export a document to a structured file, with an optional PDF snapshot.

Action Items

Action Items captures to-dos written in your Google Docs meeting notes and rolls them up into a shared spreadsheet (the Actions sheet), so anyone can see what is open, who owns it, and in which document it was assigned.

Getting started

Start a paragraph with AI:, optionally followed by an email address (or a person chip) for the assignee, then the action text — for example AI: someone@northlakeuu.org Order the new projector. Then click Sync in the side panel. Sync gives the action a permanent number (AI: becomes AI-3:) and records it in the Actions sheet. You can also type @create action and fill in the form.

Status

Each action ends with its status in parentheses, such as (Open) or (Done). Sync adds (Open) if you leave it off. To change a status, click the action's chip and choose a new one, or edit the text in the parentheses and Sync.

Side panel buttons

  • Sync — scans this document for actions and reconciles them with the Actions sheet. A background sync also runs about every 30 minutes, so edits made by people without the add-on are still picked up.
  • Import — shows open actions from other documents in your team and brings selected ones into this document.
  • Notify — reviews this document's actions as tracked in the sheet and notifies their assignees.
  • Insert Tracker — inserts or refreshes a summary table of this document's actions at the top of the document.

The same tasks are on the Extensions menu as Action Sync, Insert Tracker and Force Refresh Style. In the Actions spreadsheet, the menu offers Spreadsheet Sync All, Ensure Sheet Structure and Run Archive.

Teams

The first time a document is synced, it is assigned to a team based on the Drive folder it lives in. Import only shows actions from documents in the same team.

Allow 10–20 seconds for a sync to settle before assuming it did not work.

Format

Format applies the GC formatting rules to the open document. From the Extensions menu, GC Format opens a dialog where you choose which formatting rules to apply. GC Format (Again) applies the same choices again without the dialog.

Export

Export saves the open document as a structured file that includes its text, comments, revisions and images, with an optional PDF snapshot, into an export folder in Google Drive. Start it from Extensions → Export…. A dialog shows progress until the export finishes.

About NUUTS

Extensions → About NUUTS shows which version of the suite and its features is running. Include this when you report a problem.
